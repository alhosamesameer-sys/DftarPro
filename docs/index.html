DftarPro — دفتر Pro

إدارة الحسابات بطريقة بسيطة ومنظمة.

DftarPro هو تطبيق محاسبة وإدارة متجر مصمم لأصحاب المتاجر والأعمال الصغيرة. يساعدك على إدارة العملاء والموردين والمنتجات والمخزون والمبيعات والمشتريات والديون والمدفوعات والمصروفات والتقارير من مكان واحد.

الميزات

  • إدارة العملاء والموردين والحسابات.
  • إدارة المنتجات والمخزون والتنبيه عند انخفاض المخزون.
  • تسجيل المبيعات والمشتريات والمدفوعات والمصروفات.
  • كشوف حساب وتقارير مالية.
  • تخزين محلي للاستخدام دون اتصال بالإنترنت.
  • نسخ احتياطي واستعادة للبيانات، مع إمكانية استخدام Google Drive للنسخة الاحتياطية التي ينشئها التطبيق.

لاستخدام Google Drive، يطلب التطبيق إذن Google Drive المحدود drive.file لإنشاء أو تحديث ملف النسخة الاحتياطية الخاص بالتطبيق.

DftarPro — Account Book

DftarPro is an accounting and shop-management application for small businesses. It helps users manage customers, suppliers, products, inventory, sales, purchases, debts, payments, expenses and reports.

The application works offline-first and can create backups. When Google Drive backup is enabled, DftarPro requests the limited drive.file permission so it can create or update the backup file created by the application.
